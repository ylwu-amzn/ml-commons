Graph Memory vs Vanilla Memory — Live Comparison

Single POST /memories call populates both stores. Vanilla uses the real /memories/long-term/_semantic_search endpoint. Graph uses /memories/graph/_search plus a few stitched edge queries.
All results below are verbatim from a live OpenSearch 3.5 cluster + ml-commons plugin (branch local-test/3.5, container hV4x0Z0BrnKV8q3htQqt). Container state at capture: 22 long-term facts, 18 entities, 29 relationships.

Agentic memory stores extracted facts. Vanilla semantic search returns well-formed sentences — good for "what did we discuss?", weak for "who, what, and how are they connected?"

Graph memory adds a structured layer. In the same POST /memories call, Claude Sonnet 4.6 produces entities and typed relationships alongside the facts. The agent gets a queryable knowledge graph in addition to retrievable sentences.

Same Sonnet call. Same container. Enabling graph is one line: "enable_graph": true plus a strategy block.

Setup — one ingest populates both stores

3 realistic call notes, fed through the real agentic-memory API with infer: true. Sonnet runs two extraction passes in parallel.

Vanilla memory

The SEMANTIC strategy runs per ingest. Sonnet extracts atomic facts, ml-commons embeds them with MiniLM, writes to demo-memory-long-term. 22 facts produced from 3 call notes.

Graph memory

In parallel, GraphProcessingService runs two more Sonnet calls — one for entities, one for typed relationships — using a custom prompt that includes COMPETES_WITH, INTERESTED_IN, EVALUATING, PREVIOUSLY_WORKED_AT, MET_AT, REPORTS_TO in the vocabulary. 18 entities, 29 relationships.

Relationships Sonnet produced (counts)

WORKS_AT × 5 USES × 4 KNOWS × 5 (including Daisy <-> Mia, Elena, Jordan) EVALUATING × 4 PREVIOUSLY_WORKED_AT × 3 INTERESTED_IN × 2 MET_AT × 2 REPORTS_TO × 2 COMPETES_WITH × 1 (Initech -> Northwind Traders) MANAGES / PART_OF / …

    "custom_relationship_extraction_prompt": "Return {\"relationships\":[{\"source\":…,\"target\":…,\"type\":…,\"confidence\":…}]}. Types: WORKS_AT, KNOWS, MANAGES, REPORTS_TO, USES, INTERESTED_IN, EVALUATING, COMPETES_WITH, PART_OF, MET_AT, PREVIOUSLY_WORKED_AT, OTHER. …"
